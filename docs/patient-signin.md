# ورود مراجعان با موبایل

- بار اول که اپ باز می‌شود، صفحه «ورود مراجعان» می‌آید. مراجع شماره موبایل را وارد می‌کند (ایران با ۰۹ یا ‎+98، خارجی با پیش‌شماره کشور)، کد ۶ رقمی پیامک می‌شود و با آن وارد می‌شود.
- «ادامه بدون ورود» صفحه را می‌بندد و دیگر خودکار باز نمی‌شود؛ دکمه «ورود» بالای صفحه اول همیشه هست.
- زبان اپ از پیش‌شماره حدس زده می‌شود (‎+98 فارسی، ‎+994 آذربایجانی، ‎+90 ترکی، کشورهای عربی عربی، بقیه انگلیسی) و کاربر می‌تواند پیش یا پس از ورود آن را عوض کند. زبان روی سرور هم ذخیره می‌شود.
- حساب و توکن مراجع کاملاً از حساب کارکنان جداست (جدول `patients`، توکن نوع `patient`).

## امنیت
- کد ۲ دقیقه اعتبار دارد و فقط یک بار مصرف می‌شود؛ درخواست کد تازه کدهای قبلی را باطل می‌کند.
- ارسال دوباره حداقل ۶۰ ثانیه بعد و حداکثر ۵ کد در ساعت برای هر شماره.
- پس از ۵ تلاش اشتباه، کد باطل می‌شود.
- خود کد ذخیره نمی‌شود، فقط HMAC آن.

## تنظیم پیامک روی سرور
| متغیر | مقدار |
|---|---|
| `RAZI_SMS_PROVIDER` | `console` (فقط توسعه؛ کد در لاگ) یا `kavenegar` |
| `RAZI_SMS_API_KEY` | کلید API کاوه‌نگار |
| `RAZI_SMS_TEMPLATE` | نام قالب تأییدشده در کاوه‌نگار (با یک توکن برای کد) |
| `RAZI_OTP_DEBUG` | `true` فقط روی سرور آزمایشی: کد در پاسخ API و روی صفحه اپ نشان داده می‌شود |

سرور production بدون سامانه پیامک بالا نمی‌آید. ارسال به شماره‌های خارج از ایران به تنظیمات حساب پیامک بستگی دارد و باید با شرکت پیامک بررسی شود.
